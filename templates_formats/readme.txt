Folder with some Formats Templates in Excel format for upload to the System on the Register of Format Panel.

Instructions:
  Modify the Format:
    1-you can add more columns or rows but dont remove the exists columns or the texts insite its (some texts are used as reference for the system)
    2- you can Modify the Header of Format But dont Modify the cell with "fecha" text
    3-some cells will be fill with data from the system have it on count before write texts on the cells
  How Upload the format:
     1-Access to your System
     2-go to Registro/ Registro de Formato Panel
     3-select on the List of Formats Types the required and assign the file correspondent
 
 
Advertence!!: Some Function of System not work if the required format is not Register
